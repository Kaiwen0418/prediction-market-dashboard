# Surveillance 目录优化与对照研究（2026-10-29）

## 已实施的采集与存储策略

- 不按题材限制发现。Polymarket 自动扫描未关闭合约，Kalshi 扫描 open 且排除 MVE 组合；关闭历史/组合合约改为显式按案回填，避免枚举海量已结算及组合子合约。
- PostgreSQL 市场表只存轻量索引和生命周期状态，不存规则正文及冗长 token ID；仅监控池和手动调查合约每五分钟加载详细规则，规则正文只有一份。
- 新任务身份隔离旧查询游标。每六小时重扫，完成一轮后清理至多 50,000 个本轮未见、无案件/手动引用的旧索引；消失不等于结算。旧游标缺少 walk-start 标记时重开扫描，避免错误清理前几页。
- Polymarket 的 comboStatus 只表示普通市场作为组合腿的资格，不能作为 is_combo；默认不扫描其独立 RFQ 组合产品，保留正常体育单腿市场。
- 保留 settled、source_status、settlement_result、tradable、is_combo；深度池排除组合、initialized、暂停、已结算、proposed 及超过六小时的过期计划时间。过期时间是预算策略，不能据此宣称事件已结算；错误时间可能漏选。选池要求最近两个目录周期内观察，20% 探索配额保留。
- 关闭合约回填通过 CLI 原子加入详情与成交队列，单 worker 执行；完成后禁用手动任务，不参与自动选池。真实 received_at 保留，不伪装成事前采集。旧 Kalshi archive 仍可能需要独立适配器，错误不会被当作回填成功。
- 自动案件增加现金门槛：至少 $1,000 且至少 5 笔，或窗口现金达到 $10,000；买入和卖出都可入选。原异常评分权重未变，人工回放仍能查看原始信号。新增现金、方向、公开 taker 钱包集中度字段，版本为 v1.1。这是资源门槛，不是经过校准的内幕模型。
- 原 20 GiB 数据库 / 5 GiB raw、80%→60% 容量覆盖继续生效。此次按用户授权清空测试调查数据，不迁移或备份旧数据；普通更新不自动清空。

## 同样本存储实测

使用同一份真实市场规则生成 50,000 个合约，旧结构把完整文档同时放在目录和规则表；新结构只存轻量索引，并为 40 个合约加载详细规则。两侧采用相同表和索引布局；独立临时 schema 已删除。

| 项目 | 旧结构 | 新结构 |
|---|---:|---:|
| 目录 + 规则物理空间，含索引/TOAST | 226,967,552 B | 41,459,712 B |
| 相对占用 | 100% | 18.27% |
| SQL 批量装载耗时 | 1.099 s | 2.659 s |

存储下降 **81.73%**。样本重复同一份真实规则，不是生产增长模型；新 SQL 批量装载也没有提速，不能据此声称 worker 吞吐提升。采集范围缩小、去掉规则重复与按需详情是本次主要收益。[原始结果](catalog-storage-benchmark-2026-10-29.json)

## 对照研究

研究显式假设成交 event_time 同时就是可见时间，真实 receipt 保持今天；没有把回填写入实时数据库，没有把最终胜负、收益或当前规则喂入评分。公开市场 feed 仅 taker，钱包历史另用 maker+taker，不能把两份流合并算市场量。[配置](surveillance-controls-2026-10-29.json)及[完整结果](surveillance-controls-results-2026-10-29.json)均保存。

下表统计各区间至少一个窗口过线的“不同分钟数”，不是独立案件数；实际自动案件仍有一小时合并。观察区间时长不同，不能直接横向比较总数。

| 样本 | 原分数 ≥35 | 自动现金门槛 | 额外研究买入筛选 |
|---|---:|---:|---:|
| Maduro 报道时段，21h21m | 658 | 571 | 377 |
| Machado 公布前，15h | 612 | 461 | 175 |
| 同届 Navalnaya，15h | 444 | 166 | 5 |
| 同届 Sudan，15h | 458 | 344 | 20 |
| Maduro 更早时段，24h | 522 | 120 | 60 |
| Machado 更早时段，24h | 146 | 0 | 0 |

“额外研究买入筛选”是分数 ≥70、至少 5 笔、Yes 方向失衡 ≥0.6、名义现金 ≥$1,000，**没有部署**。金额门槛消除了 Machado 更早时段的小额告警，但对照仍会触发，远不足以识别内幕。这些是事后挑选的报道样本、同事件相关合约和较早窗口，不能当作已证实无内幕的负样本；没有估计准确率、召回率或误报率。

## 在告警当时截断的钱包补查

钱包由相应首个告警窗口中占主导方向的最大 taker 现金流选出，不按后来的盈亏、身份或赢家筛选。查询止于当次告警，最多五页，每页 1,000 条；达到上限时明确标记覆盖不完整。首次索引成交不等于开户时间。[自动门槛探查](surveillance-wallet-probes-2026-10-29.json)、[研究买入筛选探查](surveillance-buy-wallet-probes-2026-10-29.json)

- Maduro 最早自动现金门槛信号是卖出，所选钱包已有多事件历史，不能描述为提前买入。首个研究买入信号在 01-02 16:50 UTC，自动选到的公开钱包与诉状脱敏前后缀吻合；截至该时点索引返回 8 条记录、4 个相关合约，主合约占可见现金周转约 90.5%。这是交易模式复现，不是身份或私密信息来源的证明。
- Machado 研究买入信号在 10-09 22:55 UTC 选到公开昵称 6741 对应钱包；截断到该时点只有 15 条记录、2 个合约、1 个事件，最早可见记录仅约 12 分钟前。该钱包随后也出现在 Navalnaya 的首个研究买入信号中。因此这两条不是两个独立证据，跨候选人的交易必须合并调查。
- Sudan 对照的首个研究买入信号同样选到仅 1 条已索引记录、单事件 100% 集中的钱包，现金约 $9,779。**新可见钱包 + 单事件集中**不是赢家独有，也不能单独说明内幕。
- 两个活跃钱包的五页历史未穷尽，只能把集中度当作所取 5,000 条中的描述；不声称完整历史或真实净持仓。

现阶段应保留“异常→钱包/事件聚合→公开信息时间线→替代解释”的流程。下一步应扩展独立事件及预先固定的观察日期，去除同事件重复，校验广播/新闻最早公开时间，再做阈值校准。自动新闻/比赛源、历史盘口、跨平台规则等价映射仍未完成。

## 复现

```sh
python -m surveillance.research.study --config docs/research/surveillance-controls-2026-10-29.json --data-dir tmp/surveillance-research --fetch --output /tmp/study.json
python -m surveillance.research.wallet_probes --study /tmp/study.json --data-dir tmp/surveillance-research --policy research_buy_gate --output /tmp/wallets.json
```

市场分页正文/哈希和钱包原始响应保留在本次任务的 `tmp/surveillance-research/` 交付目录，不入 Git。重新联网可能得到修订后的索引或不同窗口，需保存新 receipt 并核验；已有页面通过 SHA-256 校验后可离线研究。

接口依据：[Kalshi 市场过滤](https://docs.kalshi.com/api-reference/market/get-markets)、[Polymarket v2 分页与时间过滤边界](https://docs.polymarket.com/api-reference/feeds/list-trades)。媒体案例和官方文件见此前的本地审计报告；本轮结论来自保存的公开成交与对照计算。
