# 跨事件钱包择时统计

在结算复盘每个时间片写入时，事务内计算该片段全部可归因交易的一小时价格变化。买后下跌与卖后上涨都进入负向样本。缺少未来价格的交易保留在 eligible 分母，observed 单独统计。未来价格使用下一可见五分钟成交价中位数，最多容许五分钟偏差。

同一五分钟入场桶、同结果方向、同交易方向的其他钱包提供对照，排除自身钱包。输出平均价格变化、平均相对同组表现和观测数量。统计按交易笔数加权，持仓成本、收益、身份和公开信息仍需后续调查。

`GET /wallets/{wallet}/timing` 沿用调查 API Bearer 认证，最多读取 5000 个片段，超限返回 413。只汇总已完成且未被 superseded 的复盘。相同平台原生事件的多个合约合并为一个事件样本，缺少唯一事件映射的片段单独计数。不同事件 ID 仍可能对应相关现实事件，报告保留这一限制。

至少五个有方向性对照结果的事件才显示 descriptive_sample，较小样本显示 insufficient。两种状态都是描述性结果。对照校准、多重检验和发现后样本验证仍待实施。

新增数据由时间片外键级联清理，沿用现有研究摘要记账与预算。旧时间片通过一次有界后台任务逐片补算，先验证原始输入摘要，已过期或变化的输入跳过并记录状态。新复盘事务直接生成统计。
