# 现金口径、采集缺口和多日调查优化

2026-10-29。独立调查后端已更新到本地机器；REST 采集、不自动交易、不接前端。

## 本次改动

- Kalshi NO 成交金额改用 NO 权利金，而非 YES 报价；旧逐笔 ID 保持不变，旧聚合追加修正版。方向未知则金额未知。
- 1 分钟、5 分钟、1 小时异常改用现金流突增、按金额加权的方向失衡，以及方向一致且后半窗仍保持的成交价格变化。价格代理不能证明历史扫单或可执行深度。
- 前 12 个等长基线窗，只使用采样区间覆盖且金额已知的窗口，至少 6 个才启用突增项；确认采到的零成交可以是零，缺采不能补零。自动案件要求当前窗口被采样覆盖。
- 采样凭据与成交、检查点同事务提交；区间上界使用来源成交头部，空响应按缓存 Age/max-age 保守处理。只完成请求分页仍不等于交易所无遗漏。
- 分开保存交易窗口和知识截止时间。迟到数据按来源窗口补检，真实发现时间仍是现在；手动历史回放默认不读取当时尚未收到的数据。原有 v1.1 研究工具冻结保留，不冒充新版本验证。
- 每个平台仍保留 100 个深采合约，20 个低成交探索名额、每事件最多两个。名单外每分钟筛选最多 5,000 个近期活动合约，最多 20 个待执行快速检测，并有五分钟冷却；不要求先挤入深采名单才能检测。
- 选池的活动比较改为两个完整、等长的五分钟窗；24 小时成交量明确为零时，不再退回累计成交量。不同检测版本分别冷却，旧分数不会压住新版本。
- 新入库的有效 Polymarket 钱包成交追加七个 UTC 日期的日汇总；重复页不重复累计。跨至少两天、至少六小时、三笔成交、买入金额 >=$1,000，且观察到的净买入份额保留 >=80%，可产生独立慢建仓候选。该候选分数为 null，不能据此推定真实持仓或内幕。
- 人工验证的公告锚点驱动独立结果账本：同一原生事件只计一次，保留押错、混合敞口、未知方向、未结算等状态。三个独立事件观察到的敞口与结算匹配后可生成独立复核候选。公告前成交、公告前收到数据、公告前真的建案分别记录。补入更早的公开锚点（即使没有成交）会作废按较晚锚点计算的匹配，重复候选同步更新是否仍满足门槛；历史知识版本仍可查询。结果不回写原检测分数。
- 未结算结果可触发有上限的详情刷新：全局最多 20 个待办，每小时最多重新启用一次，连续三次来源失败停止。查询接口为 `GET /wallets/{wallet}/patterns?as_of=...`。

## 容量和边界

钱包日单元最多 200,000 条，每条最多 64 个原始 receipt 引用；触顶后继续更新已有单元，跳过新单元并记录覆盖遥测。其他分页、事件、行数和引用预算见 [模块文档](../../surveillance/README.md)。新表沿用 20 GiB 数据库 / 5 GiB 原始文件准入预算、80%→60% FIFO 和七日保留；依赖凭据被覆盖时，相关案件也过期。配额不包含 WAL、镜像和压缩临时空间，不是文件系统硬上限。

慢建仓从此次部署后新入库的成交开始积累，没有伪造此前七日覆盖。重复匹配依赖保留样本、人工验证公告和可信结算，尚未形成足够样本时返回未知。没有新增 WS、自动新闻/首发/比分源、私人账户数据、钱包身份归并、跨平台等价映射或已校准的内幕概率。REST 缓存、有限重叠和未采到的数据仍可能造成漏报；这一版不能承诺研究案例必报或给出准确率。

## 验证与成本

76 项调查模块测试、54 项既有后端测试通过。新增测试覆盖 NO 金额与旧聚合修正、未知基线与观察零、迟到知识、方向相反的价格变化、重复入库、日单元封顶、名单外扫描冷却、同事件去重、结算版本、保留押错样本、结果不冒充公告前报警、案件凭据保留/FIFO，以及跨检测版本冷却。生产 API 的健康、选池、容量、钱包结果查询和未来知识时间拒绝已验证；公网 SSE 三个连续快照通过。

在本机隔离数据库 schema 内做合成压测，并在结束后删除：

| 项目 | 实测 |
|---|---:|
| 200,000 个日单元及索引（每单元一个 receipt 引用） | 63.5 MiB |
| 满日单元容量时处理 1,000 笔成交，中位数 / 最大 | 69.8 / 82.7 ms |
| 满容量慢建仓扫描 | 0.357 s |
| 50,000 笔成交、三个窗口检测，中位数 / 最大 | 0.125 / 0.126 s |

更多引用、TOAST/GIN、案件副本、原始成交和 WAL 会增加空间，63.5 MiB 不是整个调查系统的上限；共享测试 VM 上的合成测量也不是长期增长预测。[压测结果](surveillance-signal-quality-benchmark-2026-10-29.json)。

部署快照保留了实际选池、广域任务、采样区间、聚合积压、日汇总与源文件哈希：[运行快照](surveillance-signal-quality-runtime-2026-10-29.json)。启动期间基线和新汇总需要积累，健康检查不代表全市场完整、分钟级及时或能检出某个历史案例。
